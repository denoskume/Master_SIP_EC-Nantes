## Environment

This project uses an isolated Python virtual environment.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Notebook

The final executed notebook is stored in `notebooks/`.

Notebook outputs are intentionally preserved so that results, figures and metrics can be inspected directly without rerunning the project.
